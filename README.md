# TaskManager - 2ª Entrega

Gerenciador de tarefas desenvolvido em Java. Nesta segunda etapa, o projeto foi atualizado com interface gráfica, banco de dados e testes.

## Funcionalidades
- Criar e listar tarefas
- Editar e remover tarefas
- Marcar tarefas como concluídas
- Definir prioridades
- Pesquisar tarefas
- Salvar as tarefas no banco de dados

## Tecnologias
- Java 17
- NetBeans
- JavaFX
- SQLite e JDBC
- Generics
- JUnit
- Maven

## Como executar
1. Abrir o projeto no NetBeans.
2. Aguardar o Maven carregar as dependências.
3. Executar o comando `mvn clean javafx:run`.

## Testes
Para executar os testes, utilizar o comando `mvn test`.

## Sobre o projeto
O TaskManager foi desenvolvido inicialmente com interface via terminal. Nesta segunda entrega, foram adicionadas novas funcionalidades e uma interface gráfica utilizando JavaFX. Também foi implementado um banco de dados para armazenar as tarefas e testes para verificar o funcionamento do sistema.
